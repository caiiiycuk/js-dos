# Spec Delta

## Purpose

Создавать готовые к дальнейшей разработке страницы и приложения с js-dos, которые используют локальные ресурсы и работают независимо от MCP.

## ADDED Requirements

### Requirement: Поддерживаемые виды проектов

Генератор SHALL создавать в выбранной папке один из проектов `html`, `vite`, `react`, `vue` или `angular` с выбранным бандлом. Результат SHALL содержать исходники, необходимые настройки и инструкции запуска. React и Vue SHALL использовать Vite, Angular SHALL иметь совместимую стандартную сборку Angular. Неизвестный вид проекта MUST отклоняться до записи файлов.

#### Scenario: Создание каждого поддерживаемого вида
- **WHEN** пользователь выбирает любой из пяти видов и доступный локальный бандл
- **THEN** генератор создаёт соответствующий проект, возвращает его путь и команды запуска, а HTML-вариант не требует сборки Node.js

### Requirement: Локальные согласованные ресурсы

Каждый проект SHALL получать собственные копии js-dos JS/CSS, требуемых ресурсов эмуляторов и выбранного бандла. Версии runtime SHALL совпадать с поставкой MCP. Пути SHALL работать и в режиме разработки, и после сборки, без обязательных CDN-запросов или адресов временной MCP-сессии.

#### Scenario: Проверка без CDN
- **WHEN** созданный проект с самодостаточным бандлом обслуживается по HTTP при отключённой внешней сети
- **THEN** плеер и эмулятор загружаются из файлов проекта и запускают бандл

#### Scenario: Сборка проекта фреймворка
- **WHEN** проект собран поддерживаемой командой и результат обслуживается по HTTP
- **THEN** CSS, JS, WASM и бандл доступны по корректным адресам в результате сборки

### Requirement: Независимый результат без управляющего канала

Обычный запуск и production-сборка проекта MUST обходиться без запущенного MCP, его секрета и канала управления Studio. Дополнительная диагностика SHALL подключаться только явно в режиме разработки и MUST NOT попадать в обычный публикуемый результат.

#### Scenario: MCP остановлен перед открытием проекта
- **WHEN** пользователь остановил MCP и обслуживает созданный проект своим HTTP-сервером
- **THEN** локальный бандл продолжает запускаться, а страница не пытается подключиться к бывшему каналу управления

### Requirement: Жизненный цикл интеграции

Интеграции SHALL создавать плеер только после появления контейнера и освобождать его при уничтожении компонента. Повторное подключение компонента MUST NOT оставлять предыдущий эмулятор, обработчики или звук. Контейнер SHALL иметь видимые размеры, а пользователь SHALL получать понятное сообщение об ошибке инициализации.

#### Scenario: Повторное подключение компонента
- **WHEN** компонент React, Vue или Angular подключают, отключают и подключают повторно
- **THEN** остаётся только один активный плеер без фонового эмулятора от предыдущего подключения

### Requirement: Безопасная генерация и явные зависимости

Генератор MUST NOT заменять существующий непустой проект без отдельного разрешения. Неудачная генерация SHALL удалять только собственные незавершённые файлы. Генерация исходников MUST NOT скрытно устанавливать npm-пакеты или выполнять скрипты проекта. Инструкции SHALL объяснять необходимость HTTP вместо `file://`, отдельную установку зависимостей фреймворка и возможные внешние зависимости бандла. Поставка SHALL сохранять лицензии и сведения об исходниках встроенных компонентов.

#### Scenario: Папка назначения содержит пользовательские файлы
- **WHEN** агент запрашивает генерацию в непустую папку без разрешения на замену
- **THEN** генератор отказывает без изменения существующих файлов

#### Scenario: Node.js отсутствует
- **WHEN** пользователь генерирует проект фреймворка на машине без Node.js
- **THEN** исходники создаются, а результат сообщает о необходимости toolchain для установки зависимостей и сборки, не объявляя сборку проверенной
