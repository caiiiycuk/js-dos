# Spec Delta

## Purpose

Дать агенту MCP-доступ к локальной js-dos Studio из готового бинаря, сохраняя совместную работу с пользователем и ограничивая доступ к компьютеру.

## ADDED Requirements

### Requirement: Запуск готового MCP-бинаря

Поставка SHALL включать бинарные файлы для Linux, Windows и macOS, пригодные для подключения к MCP-клиенту через stdio. Запуск release-бинаря SHALL обходиться без Node.js, Rust toolchain, Tauri и Playwright; установленный браузер и задокументированные системные требования допустимы. Служебные сообщения MUST идти отдельно от протокола stdio.

#### Scenario: Подключение в OpenCode
- **WHEN** пользователь скачал соответствующий ОС бинарь и добавил его команду запуска как локальный MCP-сервер
- **THEN** клиент получает список инструментов, а сервер не требует установки npm-пакетов и не пишет логи в поток MCP

### Requirement: Локальная Studio из встроенных ресурсов

Сервер SHALL открывать Studio в браузере с локального loopback-адреса и возвращать адрес клиенту. Studio SHALL использовать встроенные в бинарь согласованные версии js-dos, CSS, JS/WASM и других необходимых ресурсов эмулятора. Базовое создание и запуск локального бандла MUST работать без доступа к CDN и публичной Studio.

#### Scenario: Запуск без внешней сети
- **WHEN** внешняя сеть недоступна, а пользователь открывает Studio и локальный самодостаточный бандл
- **THEN** Studio и эмулятор загружаются с локального сервера без запросов обязательных ресурсов на `v8.js-dos.com`

#### Scenario: Браузер не удалось открыть автоматически
- **WHEN** системная команда открытия браузера завершилась ошибкой
- **THEN** сервер возвращает понятную ошибку и локальный адрес для ручного открытия, не объявляя Studio подключённой

### Requirement: Изолированное и ограниченное соединение управления

Канал управления SHALL принимать только соединения своей сессии с проверкой адреса назначения, Origin и непредсказуемого секрета сессии. Сервер MUST слушать только loopback. Инструменты SHALL предоставлять конечный набор операций Studio и диагностики, а не произвольное выполнение JavaScript, shell-команд или чтение компьютера из веб-страницы.

#### Scenario: Посторонняя страница обращается к серверу
- **WHEN** запрос имеет чужой Origin, недопустимый Host или неверный секрет
- **THEN** сервер отклоняет запрос без выполнения операции и без раскрытия пользовательских файлов

#### Scenario: Параллельные MCP-процессы
- **WHEN** пользователь запустил два экземпляра сервера
- **THEN** каждый экземпляр имеет свой адрес и секрет, а команды одного экземпляра не управляют Studio другого

### Requirement: Явное состояние соединения и ограниченное ожидание

Сервер SHALL различать ожидание браузера, подключённую Studio и разрыв соединения. Команды SHALL иметь ограничение времени и идентификатор запроса. Результаты от предыдущего соединения MUST отклоняться; прерванные изменяющие команды MUST NOT повторяться автоматически после переподключения.

#### Scenario: Вкладку закрыли во время команды
- **WHEN** браузер отключился до подтверждения изменяющей команды
- **THEN** клиент получает ошибку соединения с признаком неизвестного результата, а после переподключения должен прочитать состояние перед повторной правкой

### Requirement: Ограниченная область файлового доступа

Импорт, экспорт, генерация и диагностика SHALL обращаться только к явно выбранным локальным источникам и папкам назначения. Сервер MUST предотвращать выход через `..`, абсолютные пути внутри архивов и ссылки за разрешённую область. Число файлов, объём распаковки и размер передачи SHALL иметь проверяемые пределы с понятной ошибкой превышения.

#### Scenario: Недопустимый путь в архиве
- **WHEN** архив содержит запись с выходом за корень бандла или превышает допустимый объём распаковки
- **THEN** импорт завершается ошибкой без записи за разрешённую область и без замены текущего бандла

### Requirement: Завершение локальной сессии

При завершении MCP сервер SHALL закрывать свой канал управления, HTTP-сервер и запущенные им процессы диагностики. Диагностика и ошибки MUST NOT содержать секрет соединения. Сохранённые пользователем проекты и экспортированные бандлы MUST сохраняться.

#### Scenario: MCP-клиент завершил соединение
- **WHEN** поток stdio закрыт
- **THEN** сервер освобождает свои сетевые ресурсы и дочерние процессы, не удаляя пользовательские результаты
